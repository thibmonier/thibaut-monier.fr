# Architecture C4

> Niveaux 1 à 3. Le site est statique : il n'y a ni serveur applicatif ni base de données. Le « système » se compose d'un **pipeline de build** et d'un **serveur de fichiers**. Décisions : ADR-0001 à ADR-0009 (`docs/adr/`).

## Flux de build et de déploiement

```mermaid
sequenceDiagram
  participant PO as PO (Docker local)
  participant GH as GitHub
  participant CI as Actions (ci.yml)
  participant RW as Railway
  PO->>PO: docker compose up dev / preview
  PO->>GH: push (branche feature/…)
  GH->>CI: PR → lint, check, Vitest, build, e2e, axe, Lighthouse
  CI-->>GH: statut vert requis
  PO->>GH: squash merge sur main
  GH->>RW: webhook de déploiement (attend la CI verte de main)
  RW->>RW: docker build --target runtime
  RW-->>PO: déployé sur thibaut-monier.fr
  Note over GH,RW: cron 06:00 UTC → redéploiement (publication programmée)
```
