Dans le négoce B2B, masquer un prix dans un gabarit ne suffit pas : le même prix reste lisible dans la Shop API et l’ajout au panier fonctionne quelle que soit la page affichée. Ce plugin applique le mode d’accès du canal côté serveur : catalogue ouvert, prix masqués ou boutique fermée derrière une connexion. Le visiteur anonyme est traité de la même façon sur les pages, l’API et le panier.
